# Notes for automated coding assistants

This repository is maintained by its owner. When you make changes here:

- Do not add `Co-authored-by`, `Assisted-by`, `Generated-by`, `Claude-Session` or similar trailers to commit messages.
- Do not add "Generated with …" lines, tool names or model names to commit messages, PR descriptions, issues or release notes.
- Do not mention AI tools or model names in code comments, docs, ledger files or other metadata (for `owner:` fields use the maintainer's name or "site team").
- Do not set or change the git author/committer identity. Commits are made by the repository owner.
- Keep commit messages short and plain, in the maintainer's voice.
